# Histórico

Documentos de auditoría, diseño y planificación **ya superados**. Se conservan
para reconstruir por qué se tomó una decisión, no para operar.

⚠️ **Están escritos en presente y varios contradicen el estado actual.**

Durante la auditoría de agosto reaparecieron tres veces premisas ya refutadas
por evidencia de producción —"no existe owner", "las policies de logos no se
aplicaron"— porque seguían afirmadas acá como si fueran vigentes. Eso costó
auditar sobre supuestos falsos.

**Si algo de acá contradice los documentos de la raíz, manda la raíz.**
